# 分鏡表：口播 B-roll 製作

> 狀態：**範本**，下面三列是示範，不是定稿。
> 這份由 agent 讀字幕（`assets/*.final.srt`）與道具表後產出，使用者在**關卡 2** 確認。
> 確認後渲染分鏡圖總表（關卡 3），再量產動畫。

## 導演說明（agent 寫在分鏡表之前；使用者在關卡 2 先看這一段）

> 觀念參考 huashu-motion 的導演、節奏、驗證三份說明，只取觀念、改寫成口播 B-roll 的版本，沒有搬它的文字。
> 每一項一兩句就好。寫不出來的項目，代表還沒想清楚，先問使用者。

- **一句話**：這支片看完，觀眾要記得什麼。
- **訊息形狀**：每一章是哪一種：宣告、流程、機制、證據、清單、對照、故事。形狀決定用哪種卡。
- **性格**：一句話，例如「清楚、親切、偏技術、不炫技」。決定緩動、密度與用色。
- **能量曲線**：開頭 3 秒的鉤子是什麼；高點在哪幾段；哪裡刻意安靜；結尾停在什麼畫面。
- **招牌動作**：全片只用一次的動作或轉場，放在哪、為什麼。
- **接續鏈**：每個轉場靠什麼把視線帶過去（延伸線、同一個道具、同一個顏色）；說不出來的就是硬切，要確定是故意的。
- **不做的事**：這支片刻意避開的手法。

## 格式規則（給 agent）

- 第一列是表頭，欄位順序不可改，腳本靠它解析。
- `起`、`訖`：旁白時間，格式 `mm:ss.s`，取自**人工校過的** srt。Beat 之間不重疊；全部接起來要涵蓋旁白，空檔要在備註說明。
- `意思類型`只能是：比較、步驟、分類、程度、概念。
- `卡片`只能是：`compare`、`branch`、`chain`、`tags`、`picture`、`icons`、`bars`、`meme`、`stage`、`rec`、`slot`（見 `src/lib/types.ts`）；道具場景用 `stage`；稿裡標【錄電腦畫面】的段落用 `rec`（佔位卡，後製放錄影）；字幕之間給「##」「###」段落卡片的停頓用 `slot`（佔位，後製放段落卡片，意思類型、道具、動作與轉場都寫 —），要用到還沒有的版型時寫 `新增:<名稱>` 並在備註說明。
- `道具`欄寫道具表的 ID，多個用頓號分隔；沒有就寫 `—`。**不得出現道具表沒有的 ID。**
- 卡片是 `rec` 的 Beat：道具欄剛好寫一個來源為「錄製」的 `rec-` ID；進場、強調、退場寫 `—`；`畫面描述`寫要錄什麼；轉場照常寫。錄影會比旁白長時，在`備註`寫「錄影延長 N 秒」，這一段之後的 Beat 開頭 N 秒不要放關鍵內容（後製時錄影會蓋過去）。其他卡片不能用 `rec-` 的 ID。
- `進場`、`強調`、`退場`、`轉場`只能用動態庫裡的名稱；`轉場`是**接下一個 Beat** 的方式，最後一個 Beat 寫 `—`。
  - 進場：`pop`、`slam`、`spinIn`、`dropIn`、`slideIn`
  - 強調：`wobble`、`pulse`、`jump`、`shake`
  - 退場：`popOut`、`slideOut`、`spinOut`
  - 轉場：`dots`、`push`、`blocks`、`doors`、`iris`、`carry`（因果鏈）
  - 以上以 `src/styles/creative-mode/MOTION.md` 為準，這裡只是抄一份給 agent 方便查。
- 用 `carry` 的兩個相鄰 Beat，兩邊的 `畫面描述` 要寫清楚線頭與接點的元件，且兩者的高度（y）要一致。
- 連續兩個 Beat 的轉場不得相同；連續三個 Beat 的進場不得相同。
- `畫面描述`寫卡片裡的文字與擺放，一格一句，要短。
