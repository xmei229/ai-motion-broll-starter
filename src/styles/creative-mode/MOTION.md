# Creative Mode · 動態描述

> 外觀：色票與字型取自 HyperFrames 的 Creative Mode 範本頁，見 `tokens.ts`。這份只寫動態。
> 程式：`src/styles/creative-mode/`（`motion.ts`、`transitions.tsx`、`CardFrame.tsx`）。
> 時間單位是**秒**，程式依幀率換算；數字以 30fps 調的。

動態分四層：動作 → 修飾 → 曲線與時長 → 編排。狀態：**已實作**（程式裡有，數字讀自程式）、**待驗**（已實作但還沒請使用者看片回驗）、**可加**（容得下但沒做）、**不做**（違反外觀規則，附理由）。

## 第 1 層：動作

### 1.1 入場

| 名稱 | 狀態 | 參數 | 程式 |
|---|---|---|---|
| **彈出**（pop） | 已實作 | 縮放 0 → 1.08 → 1，0.2 秒 | `motion.ts` `pop` |
| **拍入**（slam） | 已實作 | 縮放 2.3 → 0.9 → 1.05 → 1，0.3 秒，帶壓扁回彈 | `motion.ts` `slam` |

### 1.2 轉場（卡片與卡片之間）

每張卡自己管「進」（`transitionIn`）和「出」（`transitionOut`），前後兩張卡**不必重疊**：舊的離開、新的進來，中間版面是清空的紙底。要讓兩張卡真正重疊的轉場，等 `Film` 組合片再做。

| 名稱 | 值 | 狀態 | 出（秒） | 進（秒） | 怎麼動 |
|---|---|---|---|---|---|
| 網點 | `dots` | 已實作 | 0.26 | 0.33 | 半調網點由一點長大蓋滿；進場時由滿縮開，線性 |
| 橫推 | `push` | 待驗 | 0.4 | 0.6 | 內容整塊往左推出（`inCubic`，加速讓位）；新內容從右邊落位（`outQuart`，快進慢停）。紙底不動，版面真的被清空 |
| 色塊階梯 | `blocks` | 待驗 | 0.55 | 0.55 | 黃色色塊帶墨線，**零緩動、逐格硬跳**，從左吃到右（出）、再往右退開（進）。四跳：25%、52%、78%、100%，門檻在進度 0.05、0.33、0.58、0.85，間隔刻意不等距 |
| 對開門 | `doors` | 待驗 | 0.45 | 0.5 | 兩扇藍底網點門從左右合上（出）／打開（進），`inOutCubic`，內緣一條墨線 |
| 光圈 | `iris` | 待驗 | 0.45 | 0.55 | 墨色底，圓洞縮小到一點（出）／從一點放大（進），`inOutCubic`，洞緣一圈黃線。圓心用 `transitionAnchor`（畫面比例 0–1），預設中央 |

| 延伸 | `carry` | 待驗 | 0.9 | 0.85 | **因果鏈專用**：一條墨線加粉色箭頭，從上一張卡的某個元件往右畫出去，再與內容同步往左帶走；下一張卡的線從左緣拉到新元件的接點，內容落位後線縮回消失。前 40% 畫線、後 60% 推內容（出）；前 60% 落位、後 40% 縮線（進） |

沒有轉場：`none`。預設：進場 `dots`、出場 `none`（維持原本的樣子，已用靜止畫面驗證與改動前逐位相同）。

**`carry` 的用法**：上游元件帶出下游（因果、子題、下一個問題）。前一張卡設 `transitionOut: "carry"`、`transitionAnchor: [x, y]`，x、y 是**線頭所在的元件**在畫面上的比例位置；下一張卡設 `transitionIn: "carry"`，`transitionAnchor` 是**線要接上的新元件**的位置。**兩張卡的 y 要一樣**，不然線會在卡與卡之間跳一下。線頭停在畫面 78% 處，不出畫。

**來源與改動**（詳見 `transitions.tsx` 檔頭）：
- `carry` ← `line-carry-transition`。原卡的直角拐彎與圍框沒做，改成一條水平線；線頭停在 78% 這個數字取自原卡。
- `push` ← `bottom-push-stack-wipe`。改成往左；去掉接縫的漸層陰影（Creative Mode 只用硬偏移陰影）；出場進場分開用兩條曲線。
- `blocks` ← `color-block-step-wipe`。保留「零緩動」；原卡的徽章過衝與攜帶卡沒搬。
- `doors` ← `page-turn-transitions`（對開門那式）。**不是原卡的做法**：原卡把舊頁裂成兩半滑出，要把卡片內容渲兩份，`Icons` 卡會重複讀檔，所以改成兩扇門蓋上。立方體翻轉那式是 3D，跟 Creative Mode 的平面漫畫衝突，不做。
- `iris` ← `circle-match-iris`。只取光圈機制；原卡的重點「圓對圓匹配」要有前景圓和圈內新圖，目前沒做。

### 1.3 道具動作（`stage` 卡裡的道具）

道具是一個個獨立元件，各自進場、強調、退場，所以**不必每段都清場再蹦出**：一個退、一個留、一個換位都做得到。程式在 `props/actions.ts`，數字都是第一版起點，**待驗**。位移的單位是道具邊長的倍數。

| 階段 | 名稱 | 時長 | 怎麼動 |
|---|---|---|---|
| 進場 | `pop` | 0.2 | 縮放 0 → 1.08 → 1（沿用 `motion.ts`） |
| 進場 | `slam` | 0.3 | 從 2.3 倍落下，壓扁回彈（沿用 `motion.ts`） |
| 進場 | `spinIn` | 0.5 | 邊轉邊放大，旋轉從 −360° 減速到 0，縮放過衝約 10% |
| 進場 | `dropIn` | 0.46 | 從上方 3 倍邊長落下，落地彈起 0.18 倍再停，落地壓扁（縱向 0.85 → 1.05 → 1） |
| 進場 | `slideIn` | 0.4 | 從右（預設，與 `push` 同向）或左（`from: "left"`）4 倍邊長外滑入，`outCubic` |
| 強調 | `wobble` | 0.8 | 阻尼擺動，起始 ±12°，約 0.6 秒衰減 |
| 強調 | `pulse` | 0.3 | 縮放 1 → 1.15 → 1 |
| 強調 | `jump` | 0.4 | 往上跳 0.3 倍邊長再落下（拋物線） |
| 強調 | `shake` | 0.5 | 水平抖動，振幅 0.04 倍邊長並衰減；300 px 的道具約 12 px，控制在 14 px 內 |
| 退場 | `popOut` | 0.25 | 先放大到 1.1 再縮到 0 |
| 退場 | `slideOut` | 0.4 | 往左 4 倍邊長滑出，`inCubic` |
| 退場 | `spinOut` | 0.4 | 邊轉（−360°）邊縮小到 0，`inCubic` |

道具本身的**持續動畫**（時針會走、聲波擴散）不是動作，由道具自己用「進場後經過的秒數」算，見下面的目錄。

### 1.4 道具目錄（`props/`）

用法：`stage` 卡的 `items` 裡寫 `prop` 為這裡的 ID。新增道具：寫一個 `props/<Name>.tsx`、到 `props/index.ts` 登記、補進這張表。每個道具畫在 0–100 的座標系，墨線寬一律用 `sw`，主色用 `fill`，不要寫死。

| ID | 名稱 | 零件 | 持續動畫 | 參數（`options`） | 試過的主色 |
|---|---|---|---|---|---|
| `mic` | 麥克風 | 收音頭、網格、支架弧、立桿、底座、聲波 | 進場 0.25 秒後兩側各三道聲波輪流擴散淡出，每圈 0.67 秒 | 無 | yellow、accent、blue、white |
| `clock` | 時鐘（鬧鐘造型） | 鐘耳、錶面、刻度、時針、分針、中心點 | 時針與分針依進場後的時間走，角度由同一個分鐘數算出 | `startHour`（10）、`startMinute`（10）、`minutesPerSec`（20，0 停住） | yellow、accent、blue |

`mic`、`clock` 是**測試道具**，用來證明框架可行；正式的道具清單等「道具表」過關卡 1 之後再做。

範例：`tutorial/ep00/props-sample-stage.json`。

### 1.5 元件個別退場之外的整頁退場

整張卡的離開用 1.2 的轉場；道具個別離開用 1.3 的退場。兩個層級不要混用在同一個瞬間。


### 1.6 整片（Film）：段與段怎麼接

`Tutorial` 的 props 給 `beats`（而不是 `card`）就是整片模式：每一段（`FilmBeat`）有 `start`、`end`（整支旁白上的秒數）、一張 `card`，和 `transitionOut`（這一段接下一段的方式）。下一段沒寫 `transitionIn` 就沿用上一段的 `transitionOut`，所以兩邊不會對不上。程式在 `TutorialFilm.tsx`。

- **不重疊**：每段先退場、下一段再進場，不是兩張卡同時在畫面上。所以單卡渲出來的樣子，放進整片一模一樣。要真正重疊的轉場（兩張卡同時推）是 **可加**，還沒做。
- **轉場吃內容的時間**：每段最後 `out` 秒在退場、下一段最前 `in` 秒在進場（秒數見 1.2 的表）。卡片裡 `at` 的時間要避開這兩個窗口。
- **空檔**：段與段之間若沒接上，露出的是紙底。
- **旁白**：`audio` 填 `--public-dir` 裡的音檔。沒給就沒有旁白，只有轉場音效。
- **卡片排版**：卡片自己把各列平均分在片長內的邏輯，用的是**這一段的長度**，不是整支片長（`useCardSec`）。

**轉場音效**（`sfx.ts`，預設音量 0.5；`sfx: true` 才會掛，音效檔要先放進 assets/sfx/）：

| 轉場 | 音效檔 | 掛法 |
|---|---|---|
| dots | `transition/swoosh-quick.mp3` | 退場開始時一聲 |
| push | `transition/whoosh-fast.mp3` | 同上 |
| blocks | `ui/switch-click-quick.mp3` | **每跳一聲**（出 4 聲、進 4 聲），因為無聲的階梯會被看成卡頓 |
| doors | `mech/door-open-futuristic.mp3` | 退場開始時一聲 |
| iris | `transition/air-zoom-vacuum.mp3` | 同上 |
| carry | `text/marker-pen-line.mp3` | 同上；線在畫的聲音 |

音效全是 Mixkit 免署名、`ATTRIBUTION.md` 有登記原始網址的檔案。渲染前先複製到該集：`node tutorial/download-sfx.mjs <epNN>`。

範例：`tutorial/ep00/props-film-sample.json`（五段，用到 push、carry、blocks、iris）。

### 1.7 錄屏佔位（`rec` 卡）

教學片裡有些段落的畫面是使用者另外錄的螢幕畫面。**錄影不進 Remotion，留到後製（DaVinci Resolve 等）放入**：放大重點區域、錄影比旁白長、用 proxy 剪大檔，都在後製軟體做，也避免錄影被 Remotion 多壓縮一次。所以這些段落在 Remotion 輸出裡是 `rec` 卡：斜紋框加大字的編號（例如 `REC-04`）、要錄什麼，和這一段的起訖時間。

- 卡片寫法：`{ "kind": "rec", "title": "…", "id": "rec-04", "note": "要錄什麼", "timecode": "00:12.0–00:30.0" }`
- 靜態畫面，沒有進場動作；進退場由轉場負責，轉場照常設定。
- 後製對位：`node tutorial/review.mjs <epNN> markers` 會產生 `out/rec-markers.edl`（DaVinci Resolve 時間軸標記，每個錄屏段落一個，名稱是編號加說明，長度是該段格數）與 `out/rec-list.csv`。**EDL 匯入在 Resolve 的實測我沒做過**，匯不進去就用 CSV 的時間手動對。
- 錄影比旁白長時，錄影會蓋過下一段開頭：分鏡表備註寫「錄影延長 N 秒」，那一段開頭 N 秒不放關鍵內容。

## 第 3 層：曲線與時長

共用緩動在 `src/lib/easing.ts`（`E`、`seg`、`ip`）。Creative Mode 專屬的曲線只有 `motion.ts` 的 `pop`、`slam`。轉場的時長表在 `transitions.tsx` 的 `TRANSITION_SEC`，改數字只改那裡。

## 第 4 層：編排（暫定規則，還沒用整支片驗證）

1. **卡與卡之間一定要有轉場**，不能裸切。
2. **一支片只用 `iris` 一次**：它的能量最高，用兩次魔法就穿幫。放在一支片裡最大的轉折。
3. **`blocks` 與 `doors` 全片各不超過 3 次**，而且不連著用。
4. **連續兩個轉場不用同一種。** 同一種連用兩次，看起來像素材重複。
5. **章節之間用 `dots`**（規格本來就這樣定），**段落之間用 `push`**，這兩種是骨架；`blocks`、`doors`、`iris` 是調味。
6. **`push` 的方向固定向左**，不要混用別的方向（原卡的提醒：方向統一才有節拍感）。
7. **`blocks` 每跳要配一聲音效**：無聲的階梯容易被看成播放器卡頓（原卡的提醒）。音效素材用 `node tutorial/download-sfx.mjs <epNN>` 自己下載，掛音效等 `Film` 組合片。
8. 內容在轉場窗口內不要有別的大動作：卡片至少比「進 + 出」的總長再多留 1 秒給內容。

## 怎麼用

在 props 加欄位（都可省略）：

```json
{ "transitionIn": "push", "transitionOut": "blocks", "transitionAnchor": [0.3, 0.5] }
```

範例與審片用的影片：`tutorial/ep00/props-sample-*.json`、`tutorial/ep00/out/transitions-review.mp4`。

## 還沒做 / 要回驗

- 上面標「待驗」的四種，**只確認過靜止畫面**。動態（節奏、手感）要請使用者看 `transitions-review.mp4`，數字可能要調。
- 沒有請使用者驗過的參數都只是起點；原卡的參數是在灰階素材上調的，不保證適合 Creative Mode。
